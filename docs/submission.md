# Финальная проверка перед сдачей ДЗ 1

- [ ] Сверен отдельный пост задания из группы, если он содержит дополнения к лекциям.
- [ ] Репозиторий и README открываются преподавателю.
- [ ] Установка из чистого окружения по README проходит.
- [ ] `ruff check .`, `ruff format --check .`, `pytest -q` и offline evaluation проходят.
- [ ] `appeals doctor --live` подтверждает доступ к выбранной модели GigaChat.
- [ ] Пройдены реальные сценарии с 3–5 независимыми повторами, неудачи разобраны и отражены в отчёте.
- [ ] Проверен альтернативный реальный провайдер через другой конфиг.
- [ ] В live demo показаны нормальная обработка, ошибка инструмента, восстановление и подтверждение действия.
- [ ] Видео до 3 минут записано и доступно по ссылке.
- [ ] Ключи, `.env`, базы, приватные данные и сырой личный контент отсутствуют в коммитах/видео.
- [ ] Обновлены фактические статусы в `docs/validation.md`.
- [ ] Ссылка на репозиторий и видео переданы преподавателю разрешённым способом.
- [ ] Команда готова повторить живое демо на занятии 16 ноября.

Репозиторий: https://github.com/alexey077/agent_systems

Видео: добавить фактическую ссылку после локальной записи с реальной моделью.

Отчёт реальной модели: создаётся командой из `README.md`. Не следует указывать offline отчёт вместо него.

Текст для сдачи должен сообщать фактический результат, выбранный провайдер/модель и известные ограничения. Оценка выставляется преподавателем; самопроверка не гарантирует балл.
