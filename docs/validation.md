# Фактическая проверка ДЗ 1

Дата: 15.11.2026. Статусы относятся к проверенной версии и не являются обещанием оценки преподавателя.

## Выполнено в среде разработки

- Реализованы три предметных инструмента, полный цикл, два настоящих сетевых адаптера и отдельный scripted backend.
- 21 синтетический сценарий, по три независимых повтора в offline harness.
- Проверены права, подтверждение, отмена, запись/дедупликация, schema validation, ошибки, таймауты, некорректные источники и лимиты.
- HTTP-contract тесты проверяют native OAuth/функции/состояние GigaChat и формат альтернативного API без реальных ключей.
- Чистое окружение Python 3.12, без наследования глобальных пакетов: установка по `requirements-dev.lock` и editable install прошли.
- **73 теста прошли**, lint и проверка форматирования прошли.
- **21 сценарий × 3 повтора = 63 offline прогона, все ожидаемые проверки прошли.** Это результат harness, не accuracy реальной LLM. [Машиночитаемые результаты](offline_results.json).
- Source distribution и wheel успешно собраны через `python -m build --no-isolation`.
- GitHub Actions настроен на Python 3.11–3.13; его фактический статус проверяется после публикации коммита.

## Требует реального доступа / участия команды

| Проверка | Текущий статус | Как закрыть |
|---|---|---|
| Реальный GigaChat OAuth и модель | Не выполнялся: ключ отсутствует в окружении разработки | Локальный `.env`, `appeals doctor --live` |
| Качество реальной модели, 3–5 повторов | Не выполнялось | `appeals evaluate --repeats 3 --output runtime/gigachat/report.json` |
| Реальная смена на альтернативный backend | Адаптер проверен HTTP-contract тестами, backend не запускался | Запустить Ollama и команду с `config/ollama.toml` |
| Видео до 3 минут | Не записано | Записать настоящий прогон по `docs/demo.md`, добавить ссылку |
| Демо 16 ноября | Предстоит | Показать на занятии |
| Дополнения отдельного поста в группе | Пост не предоставлен | Сверить с преподавателем/группой |

Ключ пользователя не запрашивался в чате и не помещался в Git. Успешные offline прогоны не называются измерением качества GigaChat. Реальные неудачи сохраняются в отчёте, а не исключаются ради красивой accuracy.
