# Агент обработки обращений граждан · ДЗ 1

Агент помогает сотруднику разобрать синтетическое обращение: определяет тему и приоритет, получает учебного адресата, ищет публичные материалы ФНС и готовит черновик со ссылками. Когда оснований недостаточно, создаёт задачу ручного разбора **после подтверждения человеком**. Официальные письма агент не отправляет.

Требования: [матрица ДЗ 1](docs/requirements.md). Предметная постановка: [спецификация](docs/specification.md). [Полные контракты трёх инструментов](docs/tool_contracts.md). Фактические проверки и незакрытые пункты: [validation.md](docs/validation.md).

## Быстрый старт

Python **3.11–3.13**, Git. Выполняйте команды из корня репозитория.

```bash
git clone https://github.com/alexey077/agent_systems.git
cd agent_systems
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.lock
python -m pip install --no-deps -e .
cp .env.example .env
```

В Windows PowerShell окружение активируется командой `.venv\Scripts\Activate.ps1`.

В локальном `.env` заполните **Authorization Key**, полученный в Studio:

```dotenv
GIGACHAT_CREDENTIALS=значение_только_в_локальном_файле
GIGACHAT_SCOPE=GIGACHAT_API_PERS
```

Не коммитьте `.env`. `.gitignore` уже исключает его, базы и runtime-трассы. Приложение не выводит ключ. При компрометации ключ следует перевыпустить в кабинете провайдера.

```bash
appeals doctor
appeals doctor --live
appeals run --scenario account_normal --trace
appeals run --text 'Не получил налоговое уведомление. Где его найти?' --trace
appeals queue
```

`doctor --live` проверяет OAuth и получает доступные модели без вывода токена. Убедитесь, что `configured_model_available=true`; при необходимости укажите доступную модель в `config/gigachat.toml`. Требуется действующий лимит API.

Если возникла ошибка доверия TLS, установите требуемые провайдером корневые сертификаты согласно [официальной инструкции](https://developers.sber.ru/docs/ru/gigachat/certificates) или задайте `GIGACHAT_CA_BUNDLE` как путь к доверенному PEM bundle. Проверка TLS в коде не отключается. URL, модель, таймауты, лимиты и провайдер задаются конфигом, ключи только окружением.

## Где используется GigaChat API

GigaChat получает обезличенный текст, системные правила и схемы инструментов. Возвращает запрос функции или итоговый JSON. Harness проверяет запрос, выполняет Python-функцию, возвращает результат модели и продолжает цикл. Модель выбирает порядок вызовов по результатам, а не следует жёстко записанной цепочке.

| Инструмент | Тип | Что делает |
|---|---|---|
| `search_knowledge_base` | Чтение | Поиск по атрибутированным публичным материалам, максимум 5 фрагментов |
| `get_routing_rules` | Чтение | Учебная очередь и критерии приоритета по теме |
| `escalate_to_operator` | Действие | Подтверждаемая запись задачи сотруднику в SQLite |

Адресат и URL итоговой карточки восстанавливаются кодом по справочнику и найденным source IDs. Идентификатор обращения, сотрудник, организация, права, подтверждение и ключ идемпотентности не выбираются моделью. При недоступности модели/инструмента, плохом JSON, зацикливании или лимите возвращается контролируемая карточка ручного разбора.

## Альтернативный реальный провайдер

Поддержан отдельный адаптер OpenAI-compatible Chat Completions. Например, локальный Ollama:

```bash
ollama pull qwen3:8b
```

Запустите Ollama и добавьте в `.env` `COMPATIBLE_API_KEY=ollama` (локальная заглушка для формата авторизации, не секрет сервера). Затем:

```bash
appeals --config config/ollama.toml run --scenario account_normal --trace
```

Для другого совместимого сервера измените `base_url`, `model`, `credentials_env` в копии конфига. У модели должна быть поддержка tools. Одинаковая логика агента работает с native GigaChat и совместимым API. Реальный backend нельзя подменять scripted-режимом при демонстрации смены провайдера.

## Проверки

```bash
ruff check .
ruff format --check .
pytest -q
appeals --config config/offline.toml evaluate --repeats 3 --output runtime/offline/report.json
python -m build --no-isolation
```

Offline-режим воспроизводит записанные вызовы, выполняя **настоящие инструменты, валидацию, SQLite и обработку ошибок**. Он не обращается к LLM, не измеряет качество GigaChat и всегда явно маркируется `offline-scripted`.

Реальная модель, каждый из 21 сценария по 3 раза:

```bash
appeals evaluate --repeats 3 --output runtime/gigachat/report.json
```

Этот прогон платный/расходует лимит согласно вашему тарифу. Подтверждения в eval-наборе симулируются тестовой средой для синтетических данных; в обычном `run` и `demo` подтверждение всегда интерактивное. Оценка возвращает ненулевой код при провале хотя бы одного сценария. Разберите неудачные трассы, исправьте причины и повторите прогон. Методика и ограничения: [evaluation.md](docs/evaluation.md).

## Демо и сдача

```bash
appeals demo
appeals demo --fault
```

Второй сценарий искусственно вызывает таймаут **справочного инструмента**, сохраняя реальную модель. Во время передачи оператору проверьте карточку и введите `ПОДТВЕРЖДАЮ`. Запись без интерактивного подтверждения не выполняется. [Сценарий видео на 3 минуты](docs/demo.md), [чек-лист сдачи](docs/submission.md).

## Устройство репозитория

- `src/citizen_agent/`: цикл, три инструмента, два сетевых адаптера, конфигурация, хранилище, защита журналов, CLI и eval-runner.
- `config/`: GigaChat, альтернативный провайдер, явно обозначенные offline fixtures.
- `data/`: база знаний, учебная маршрутизация, 21 синтетический сценарий с ожиданиями.
- `tests/`: функции, цикл, HTTP-контракты провайдеров, ошибки, права, конфиг, журналирование.
- `docs/`: требования, спецификация, контракты, архитектура, источники, методика оценки и демо.
- `.github/workflows/ci.yml`: lint, format, тесты, offline evaluation и сборка на Python 3.11–3.13.

## Ограничения

Пять предметных тем ФНС и `other` описывают заявленный учебный контур. Локальные очереди не являются официальной структурой ФНС. Нет доступа к персональным начислениям или статусам деклараций. Публичные материалы сохранены как краткие пересказы с датой проверки; перед эксплуатацией их необходимо обновлять. Контроль source IDs гарантирует происхождение ссылок, но не доказывает фактическую полноту каждого предложения LLM. Regex-маскирование и detection injection не являются полной DLP/защитой от всех атак. Для проекта допустимы только синтетические и публичные данные. CLI работает как локальное приложение одного доверенного сотрудника, не как многопользовательский авторизованный сервис.
